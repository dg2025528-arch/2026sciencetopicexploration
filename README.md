# Anthocyanin Lab V3

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 기능
- pH 4~10, 완충용액/추출액 부피, H₂O₂ 처리 여부, 관찰 시간 설정
- 25 °C 고정 표시, 속도상수 직접 설정 없음
- 교육용 가정 시뮬레이션과 용액 색 변화 시각화(용액 부피 일정)
- CSV 데이터 품질 검사, 원본·정규화 그래프, 평균 흡광도 감소 속도
- 0차·1차·2차 수학적 모형 비교 및 조건별 비교
- 화학 개념 11개, JSON 조건 저장/불러오기, 보고서 요약 내보내기

## CSV 형식
필수 열: `time`, `pH`, `group`, `absorbance`

## 주의
시뮬레이션은 실제 반응을 예측하거나 검증한 모델이 아닌 교육용 가정 모델입니다. 추정되는 값은 흡광도 기반 겉보기 값입니다. pH에 따른 화학종과 몰흡광계수 차이를 고려해 해석하세요.
